Календарь группы — кто может выйти на концерт.

Приложение само по себе данные не хранит. Нужен проект Firebase: почта, общая база и пуши на телефон.

1. Откройте https://console.firebase.google.com и создайте проект.
2. Добавьте приложение Android. Имя пакета: ru.sostav.app
3. Скачайте google-services.json и положите его в папку app (рядом с build.gradle.kts).
4. В Firebase включите Authentication → Email/Password.
5. Создайте базу Cloud Firestore в режиме production.
6. Установите Firebase CLI и в папке проекта выполните:
   firebase login
   firebase use --add
   firebase deploy --only firestore:rules,functions
7. Пуши работает Cloud Function. Для неё нужен тариф Blaze (платёжный счёт, для группы из нескольких человек обычно остаётся в бесплатном лимите). Календарь и вход работают и без функции, но уведомления на телефон придут только после этого шага.
8. Откройте папку календарь в Android Studio и соберите APK: Build → Build APK. Либо из этой папки: gradlew.bat assembleDebug
9. Файл «Календарь группы 1.0.3.apk» появится в app\build\outputs\apk\debug. Следующую сборку называйте выше: в app\build.gradle.kts поднимите releaseVersion и releaseCode, соберите APK и выполните publish.ps1. Скрипт кладёт файл в релиз GitHub. Уже установленное приложение само видит новый релиз, скачивает его и перед установкой сверяет подпись. Файл с другой подписью не ставится.

Первый, кто создаёт группу, становится админом. Код приглашения — на вкладке «Группа». Админ может назначить других админов, сменить код и удалить человека. Чужие отметки «могу / не могу» не правит никто. Концерт может создать любой участник.
